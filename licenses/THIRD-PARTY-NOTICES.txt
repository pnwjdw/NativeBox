  Replaces the SQLite 3.49.1 code present in the original upstream Qt plugin.
  SQLite is public domain; Qt SQL driver source remains under its Qt LGPL terms.
  Exact source URLs and published digests are in dependencies.lock.json.
  Build recipe: scripts/prepare-sqlite.py and the native CMake ExternalProject recipe.
  The upstream installed Qt SDK tree is not modified.
  Local build enables SQLite defensive mode and disables trusted schema by default.
